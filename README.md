# Substance Database API (Python)

FastAPI-based API for managing chemical substances.

## 🔧 Development

```bash
docker-compose up --build
```

Then open: [http://localhost:3000/docs](http://localhost:3000/docs)

## 🔁 Endpoints
- `GET /substances`
- `POST /substances`
- `GET /substances/{id}`
- `PUT /substances/{id}`
- `DELETE /substances/{id}`
